# Visual direction

## Central metaphor

Show one short sentence entering a clear production path. It passes through three stations: idea, explanation, and video. The path stays visible while each station changes state. This makes the workflow itself the concept visual.

## Beat map

| Beat | Visual state | Narration cue |
| --- | --- | --- |
| 0–8 seconds | One sentence card appears and its question mark lights up | “Can one simple sentence become a complete video?” |
| 8–19 seconds | Facts, script, and visual scenes connect into a three-step path | “First… Then each part…” |
| 19 seconds onward | A vertical video frame fills with scene, voice, and timed words | “When the narration is ready… Finally…” |

## Motion and layout

- Keep the OneLine Studio lockup in the upper-left brand area and the tagline in the upper-right.
- Animate one cyan packet along the path. Let each production stage change from outline to amber focus, then green completion.
- Keep the main diagram between the header and subtitle band. Captions stay in the lower safe area.
- Use high-contrast labels and short text. Do not place paths behind captions.
- Make the browser and Pillow scenes tell the same story with the same three stages.
- Review active word highlighting at several times inside the same spoken phrase.
