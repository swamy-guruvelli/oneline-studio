# Video style templates

Each subfolder in this directory is a reusable video style. The available `explainer/` template is for short concept explanations with a hook, a mental model, a worked example, narration, optional subtitles, and a useful close.

When a request needs a different format, use an existing matching style if available. Otherwise create a new style folder with its own visual rules, scene starter, and README. Reuse the shared project, narration handoff, timing, rendering, and review conventions where they fit.
